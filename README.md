# World News · 25 November 2026

Run `python3 main.py` with Python 3.13 and Pillow 11.1.0 to write
`/output/entry.png`. The renderer uses Pillow's embedded TrueType font and
the six stories in `main.py`. It runs offline and needs no asset files.

The local make.fun kit specifies a standard-library-only grader. This
Pillow version of the renderer requires Pillow to be available at runtime.
